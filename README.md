# 🏦 Bank Customer Churn Prediction

Predicts whether a bank customer will leave the bank (Churn) or stay, using Machine Learning.

## 📌 Problem Statement
Banks lose money when customers leave. This model helps banks identify customers who are likely to leave, so they can retain them.

## 🛠️ Tools & Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Random Forest Classifier
- Google Colab

## 📂 Project Structure
- Bank_Churn_Model.pkl.ipynb - Main Model Training Notebook

## 📊 Model Performance
- Algorithm: Random Forest Classification
 - Accuracy: ~86% 

## ▶️ How to Run
1. Open `Bank_Churn_Model.pkl.ipynb` in Google Colab
2. Click Runtime -> Run All
3. Model will train and show accuracy and confusion matrix
